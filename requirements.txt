# RankAlpha — runtime dependencies (Python 3.12; developed and pinned on 3.12.3)
#
# EXACT pins, deliberately (#25 finding D-1). Every line used to be `>=`, which contradicts
# the project's central claim: the LightGBM ranker is FROZEN — fit once on 2024-05-15,
# never refit — and every published number is a measurement of that one model's scores. A
# `pip install` that resolved a different LightGBM would silently produce different scores,
# a different ranking, a different pie, and different figures, while every doc still said
# "frozen". The JS side already pins exactly (`next 15.5.4`, `react 19.1.1`); this is the
# side where it actually matters.
#
# Versions below are the ones in the venv that produced the committed artifacts.
# To upgrade: change a pin deliberately, re-run `make test-all`, and re-check the scorecard
# — never by re-resolving.
